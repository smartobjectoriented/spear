==========================
Request modes and evidence
==========================

SPEAR does not treat every request the same way. It reads the class of each
request — GENERAL, IMPLEMENTATION, NORMATIVE or :term:`MIXED` — and runs it on the path
where its evidence can be kept: changes on the :term:`coding core` behind its control
plane, questions about a standard on the :term:`normative runtime`, and changes that
must satisfy a standard through both, judged on evidence the model cannot
supply.
